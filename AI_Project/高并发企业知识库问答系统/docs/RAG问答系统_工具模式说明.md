# RAG问答系统 - 工具模式说明

## ✨ 更新内容

`RAG问答系统.py` 已升级，现在支持**两种运行模式**：

### 1. 普通模式（默认）
- 功能：文档检索 + LLM问答
- 特点：快速、稳定、成本低
- 适用：日常技术问答

### 2. 工具模式（阶段3新增）⭐
- 功能：文档检索 + LLM问答 + **5个工具调用**
- 特点：智能、多步推理、功能强大
- 适用：需要计算、转换、表格等场景

---

## 🚀 使用方法

### 方式1：直接运行（推荐）

```bash
python RAG问答系统.py
```

启动后选择模式：
```
❓ 选择运行模式：
  1. 普通模式 (仅文档检索+LLM问答)
  2. 工具模式 (支持计算、单位转换、表格生成等)

请选择模式 (1/2，默认1):
```

### 方式2：通过main.py

```bash
python main.py qa
```

也会出现模式选择提示。

### 方式3：程序化调用

```python
from RAG问答系统 import RAGQASystem

# 普通模式
rag = RAGQASystem(
    vector_db_path="./embedding向量库",
    llm_model="qwen-turbo",
    enable_tools=False  # 默认False
)
result = rag.ask("F30的测距范围是多少？")

# 工具模式
rag_with_tools = RAGQASystem(
    vector_db_path="./embedding向量库",
    llm_model="qwen-turbo",
    enable_tools=True  # 启用工具
)
result = rag_with_tools.ask_with_tools("计算 100 * 2.5")
```

| 工具 | 功能 | 示例 |
|------|------|------|
| **Calculator** | 数学计算 | "计算 (100 + 50) * 2" |

| **Table Generator** | 表格生成 | "生成产品对比表格" |
| **Document Search** | 文档搜索 | "搜索ADS6311文档" |

## 🎯 何时使用工具模式？

### 适合工具模式的场景：
- ✅ 需要数学计算
- ✅ 需要单位转换
- ✅ 需要生成表格
- ✅ 需要提取结构化参数
- ✅ 需要多步推理
- ✅ 复杂的组合任务

### 适合普通模式的场景：
- ✅ 简单的技术问答
- ✅ 文档检索和摘要
- ✅ 需要快速响应
- ✅ 成本敏感
- ✅ 不需要工具能力

## ⚠️ 注意事项

1. **成本控制**：工具模式可能调用LLM多次，注意API成本
2. **依赖安装**：工具模式需要安装LangChain
3. **错误恢复**：工具模式失败时会自动回退到普通模式
4. **向量数据库**：Document Search工具需要已构建的向量库

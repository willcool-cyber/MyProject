## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置API Key

```bash
# Windows
set DASHSCOPE_API_KEY=your_api_key_here

# Linux/Mac
export DASHSCOPE_API_KEY=your_api_key_here
```

### 3. 构建向量库

```bash
cd src
python RAG数据库.py
```

### 4. 启动Web UI

#### 方式1：使用启动脚本（推荐）

```bash
# 双击运行
启动WebUI.bat

# 或命令行
.\启动WebUI.bat
```

#### 方式2：直接启动

```bash
streamlit run app.py
```

浏览器访问：**http://localhost:8501**

## 🎯 使用指南

### 1. 初始化系统

- 点击侧边栏的 **"🚀 初始化系统"** 按钮
- 等待3-5秒加载完成
- 查看系统状态确认初始化成功

### 2. 开始提问

**方式1：输入问题**
- 在底部输入框输入问题
- 点击"🚀 发送"或按Enter提交

**方式2：快速问题**
- 点击右侧的示例问题按钮
- 系统自动处理并返回答案

### 3. 调整参数

在侧边栏可以调整：

- **检索文档数量（top_k）**
  - 默认值：5
  - 范围：1-10
  - 说明：越大越全面，但可能引入噪音

- **LLM温度（temperature）**
  - 默认值：0.8
  - 范围：0.1-1.0
  - 说明：越高越随机，越低越确定

- **相似度阈值（threshold）**
  - 默认值：0.4
  - 范围：0.0-1.0
  - 说明：过高可能找不到相关文档

### 4. 查看来源

- 每个回答下方有"📚 参考文档"展开项
- 点击可查看详细的文档来源和相似度分数
- 支持混合检索时会显示多维度分数

```toml
[server]
port = 8080  # 改为其他端口
```

### 自定义主题

编辑 `.streamlit/config.toml`：

```toml
[theme]
primaryColor = "#FF6B6B"      # 主题色
backgroundColor = "#FFFFFF"    # 背景色
secondaryBackgroundColor = "#F0F2F6"  # 次要背景色
textColor = "#262730"         # 文字颜色
```

```bash

pip install rank-bm25 jieba
```

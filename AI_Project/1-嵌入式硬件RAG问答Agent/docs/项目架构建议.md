## 📝 每个文件的职责说明

### 核心模块（core/）

#### `document_parser.py` - 文档解析器
```python
# 职责：解析各种格式文档
class DocumentParser:
    - parse_pdf()
    - parse_pptx()
    - parse_xlsx()
    - parse_docx()
```

#### `vector_database.py` - 向量数据库
```python
# 职责：向量化和存储
class VectorDatabase:
    - build_index()
    - search()
    - add_documents()
    - save() / load()
```

#### `rag_engine.py` - RAG引擎
```python
# 职责：检索增强生成
class RAGEngine:
    - retrieve()
    - generate_answer()
    - hybrid_search()
```

#### `llm_client.py` - LLM客户端
```python
# 职责：封装LLM API
class LLMClient:
    - chat()
    - stream_chat()
    - embed()
```

---

### 配置模块（config/）

#### `settings.py` - 全局配置
```python
# 职责：管理所有配置
class Settings:

    - CHUNK_SIZE
```

#### `prompts.py` - Prompt模板
```python
# 职责：管理所有Prompt
PROMPTS = {
    "qa": "...",

    "analysis": "..."

```

### Agent模块（agents/）

#### `base_agent.py` - 基础Agent
```python
# 职责：Agent基类
class BaseAgent:
```

```python
# 职责：处理问答任务
class QAAgent(BaseAgent):
```

```python
# 职责：处理搜索任务
class SearchAgent(BaseAgent):
```

## 💡 关键设计原则

1. **单一职责**：每个文件/类只做一件事
2. **松耦合**：模块间依赖最小化
3. **可测试**：每个模块都可独立测试
4. **可扩展**：易于添加新功能
5. **配置分离**：配置与代码分离
6. **错误处理**：完善的异常处理
7. **日志记录**：关键操作都有日志

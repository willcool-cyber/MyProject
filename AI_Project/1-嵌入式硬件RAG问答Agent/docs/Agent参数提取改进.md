# 🔧 Agent 参数提取功能改进

## 📋 问题分析

### 原始问题

**问题 1**: 计算器参数提取不准确
```
输入: "计算激光雷达最大和最小测距的比值（30米和0.1米）"
旧版本: {'expression': '30'}  ❌ 只提取了第一个数字
期望: {'expression': '30 / 0.1'}  ✅
```

**问题 2**: 单位转换参数提取失败
```
输入: "将F30激光雷达的30米测距转换为厘米"
旧版本: {'from_unit': '激光雷达的30米测距转换为厘', 'to_unit': '米'}  ❌ 单位识别错误
期望: {'value': 30, 'from_unit': 'm', 'to_unit': 'cm'}  ✅
```

## ✅ 解决方案

### 1. 增强计算器参数提取

#### 支持的模式

**模式 1**: 直接数学表达式
```python
"计算 10 + 5 * 2" → {'expression': '10 + 5 * 2'}
"100 - 50 + 20" → {'expression': '100 - 50 + 20'}
```

**模式 2**: 自然语言转换（智能关键词识别）
```python
# 除法/比值
"30米和0.1米的比值" → {'expression': '30 / 0.1'}
"100除以5" → {'expression': '100 / 5'}

# 加法
"10加5" → {'expression': '10 + 5'}
"求和100和200" → {'expression': '100 + 200'}

# 减法
"100减去50" → {'expression': '100 - 50'}

# 乘法
"10乘以5" → {'expression': '10 * 5'}
"3的5倍" → {'expression': '3 * 5'}
```

#### 关键词映射表

| 运算 | 关键词 |
|------|--------|
| 除法 | 比值、除以、除、商 |
| 加法 | 和、加、总和、求和、相加 |
| 减法 | 差、减、相减 |
| 乘法 | 积、乘、相乘、倍 |

## 🔍 核心代码实现

### 计算器参数提取逻辑

```python
def _extract_tool_params(self, query: str, tool_name: str):
    if tool_name == 'calculator':
        # 1. 尝试提取现成的数学表达式
        expr_match = re.search(r'([\d.]+\s*[+\-*/]\s*[\d.]+(?:\s*[+\-*/]\s*[\d.]+)*)', query)
        if expr_match:
            params['expression'] = expr_match.group(1).strip()
        else:
            # 2. 提取所有数字
            numbers = re.findall(r'\d+\.?\d*', query)
            if len(numbers) >= 2:
                # 3. 根据关键词判断运算符
                if any(kw in query for kw in ['比值', '除以', '除', '商']):
                    params['expression'] = f"{numbers[0]} / {numbers[1]}"
                elif any(kw in query for kw in ['和', '加', '总和', '求和']):
                    params['expression'] = f"{numbers[0]} + {numbers[1]}"
                # ... 其他运算符
```

### 单位转换参数提取逻辑

```python
def _extract_tool_params(self, query: str, tool_name: str):
    if tool_name == 'unit_converter':
        # 1. 单位映射表
        unit_map = {'米': 'm', '厘米': 'cm', ...}
        
        # 2. 提取数值
        value_match = re.search(r'(\d+\.?\d*)', query)
        params['value'] = float(value_match.group(1))
        
        # 3. 提取单位（支持中英文混合）
        pattern = r'(\d+\.?\d*)\s*(米|cm|mm|...).*?(?:转换为|转成)\s*(米|cm|mm|...)'
        match = re.search(pattern, query)
        
        if match:
            params['from_unit'] = unit_map.get(match.group(2))
            params['to_unit'] = unit_map.get(match.group(3))
```


   ```
   ❌ 30转成厘  → 单位不完整
   ✅ 30米转成厘米
   ```

3. **数字和单位间可以有空格**
   ```
   ✅ 100 米
   ✅ 100米
   ```

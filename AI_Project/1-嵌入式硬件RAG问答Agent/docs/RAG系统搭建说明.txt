class DocumentParser:
    """文档解析器：支持PDF、PPTX、XLSX"""
    
    @staticmethod
    def parse_pdf(file_path: str) -> str:
        """解析PDF文件"""
        text = ""
        try:
            with open(file_path, 'rb') as file:
                pdf_reader = PyPDF2.PdfReader(file)
                for page in pdf_reader.pages:
                    page_text = page.extract_text()
                    if page_text:
                        text += page_text + "\n"
        except Exception as e:
            print(f"❌ 解析PDF失败 [{file_path}]: {e}")
        return text
```

### 支持的文件格式：

| 格式 | 解析器 | 用途 |

### 分块策略：

```

"ADS6311是一个SPAD芯片。它具有高灵敏度。

分块过程：
1. 清理文本（去除多余空白）

3. 在句子边界处调整（找到 '。' 或 '! ' 等）

```@e:\AI_Code\嵌入式硬件RAG问答Agent\src\RAG问答系统.py#247:329
def ask(self, 
        query: str, 
        top_k: int = 5,
        temperature: float = 0.8,
        similarity_threshold: float = 0.4,
        stream: bool = False,
        use_cache: bool = True,
        use_history: bool = True) -> Dict[str, Any]:
    """
    执行RAG问答（支持流式输出、缓存和对话历史）
    """
    # 1. 选择检索策略
    if self.use_hybrid_search:
        search_results = self.vector_db.hybrid_search(
            query, 
            top_k=top_k,
            semantic_weight=0.7,
            keyword_weight=0.3,
            rerank=True
        )
    else:
        search_results = self.vector_db.search(query, top_k=top_k)
    
    # 2. 过滤低相似度文档
    filtered_results = [
        doc for doc in search_results 
        if doc['similarity_score'] >= similarity_threshold
    ]
    
    # 3. 构建Prompt
    prompt = self.build_prompt(query, filtered_results)
    
    # 4. 调用LLM
    if stream:
        responses = Generation.call(
            model=self.llm_model,
            prompt=prompt,
            temperature=temperature,
            stream=True
        )
```

这个系统的真正价值在于**系统性的完整性**和**工程化的专业性**，而不是单一的技术创新。它展示了如何将多个技术组件（向量检索、关键词检索、LLM、Agent工具链）有机地整合在一起，形成一个高效、易用的RAG系统。
